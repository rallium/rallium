## The mark

Convergence: six strokes rallying inward to a single warm core. The name is a coinage,
"rally" (to bind many back into one) plus "-ium". The warm core is the rallying point.

| File | Use |
|------|-----|
| `rallium-mark.svg` | Primary mark, for light backgrounds |
| `rallium-mark-light.svg` | For dark backgrounds |
| `rallium-mark-mono.svg` | Single color, for stamps / one-color printing |
| `rallium-favicon.svg` | Mark on a Midnight tile, legible at small sizes |
| `rallium-wordmark.svg` | Horizontal mark + wordmark lockup |
| `rallium-mark.png`, `rallium-mark-light.png` | Raster marks, 1024 px |
| `favicon-16/32/48/180/512.png` | Favicon and app-icon sizes |

Keep clear space around the mark equal to the diameter of the core. Do not recolor,
rotate, restretch, or add effects to the mark.

## Color

| Token | Hex | Use |
|-------|-----|-----|
| Midnight | `#14213A` | Ink, surfaces, the field |
| Flare | `#FF6A3D` | The core / rallying point. Accent, one per view |
| Signal | `#3B6EF6` | Links, supporting lines |
| Slate | `#8A94A6` | Secondary text, labels |
| Mist | `#EBEEF3` | Light surface, dividers |
| Paper | `#F5F6F8` | Light background |

Cool field, one warm point. Flare is the only warm element; use it sparingly.

## Type

Wordmark and display: a geometric grotesk, heavy weight, tight tracking; the "i" is set in
Flare. Interface and body: a clean grotesk. Data and command line: a monospace. The
production wordmark face is to be finalized; Inter is the recommended open option.
